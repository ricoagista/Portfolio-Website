Catatan Istilah Presentasi

Tidak ada istilah yang cocok dengan pencarian.

A. Istilah Organisasi & Konteks

PT PLN (Perusahaan Listrik Negara) Persero

Perusahaan listrik milik negara Indonesia. Salah satu perusahaan energi terkemuka di Indonesia.

UP2D S2JB

Singkatan dari Unit Pelaksana Pengatur Distribusi – Sumatera Selatan, Jambi, dan Bangka Belitung. Unit kerja PLN yang mengatur distribusi listrik di wilayah tersebut. Ini objek penelitiannya.

WLAN (Wireless Local Area Network)

Jaringan komputer lokal tanpa kabel, biasanya pakai WiFi.

IEEE 802.11

Standar internasional untuk jaringan WiFi. Kalau kamu lihat "802.11 Deauthentication" artinya serangan pada protokol WiFi versi itu.

SSID (Service Set Identifier)

Nama jaringan WiFi yang muncul di HP/laptop kamu. Contoh: "PLN_Guest" atau "WiFi_Kantor".

B. Istilah Keamanan Umum

Vulnerability (Kerentanan)

Celah atau kelemahan pada sistem yang bisa dimanfaatkan penyerang.

Exploitation (Eksploitasi)

Tindakan memanfaatkan celah tersebut untuk menyerang.

Threat (Ancaman)

Potensi bahaya yang bisa menyerang sistem.

Penetration Testing (Pentest)

Uji coba menyerang sistem dengan izin resmi, tujuannya mencari celah sebelum penyerang asli menemukannya. Ibaratnya: kamu menyuruh "pencuri profesional" mencoba membobol rumahmu, supaya kamu tahu di mana lemahnya.

PTES (Penetration Testing Execution Standard)

Standar internasional yang mengatur tahapan pentest. Ada 7 tahap (lihat gambar Fig. 1 di jurnal).

Firewall

Sistem keamanan yang menyaring lalu lintas data masuk/keluar jaringan. Seperti satpam yang memeriksa tamu.

IDS/IPS (Intrusion Detection System / Intrusion Prevention System)

IDS = sistem yang mendeteksi serangan.
IPS = sistem yang mendeteksi dan langsung memblokir serangan.

C. Istilah Perangkat Jaringan

Access Point (AP)

Perangkat pemancar WiFi. Biasanya berbentuk kotak dengan antena, dipasang di langit-langit kantor.

AP Isolation (Isolasi Access Point)

Fitur yang membuat setiap pengguna WiFi tidak bisa saling berkomunikasi satu sama lain. Kalau fitur ini aktif, user A tidak bisa mengintip data user B. Kalau tidak aktif (kasus di jurnal ini), penyerang bisa lebih mudah menyerang.

MAC Address

Alamat unik setiap perangkat (HP/laptop) yang diberikan pabrik. Seperti nomor KTP perangkat.

MAC Filtering

Fitur yang hanya mengizinkan perangkat dengan MAC Address tertentu untuk konek WiFi. Seperti daftar tamu undangan.

IP Address

Alamat logis perangkat di jaringan. Seperti alamat rumah di internet.

DHCP (Dynamic Host Configuration Protocol)

Layanan yang otomatis memberikan IP Address ke perangkat yang baru konek WiFi.

DNS (Domain Name System)

Layanan yang menerjemahkan nama website (misal google.com) menjadi IP Address.

Broadcast

Cara mengirim data ke semua perangkat di jaringan sekaligus, bukan ke satu perangkat saja.

Auto-connect

Fitur di HP/laptop yang otomatis menyambung ke WiFi yang pernah terhubung. Ini berbahaya kalau ada WiFi palsu dengan nama sama — HP kamu bisa otomatis konek ke WiFi palsu itu.

Static ARP Entries / ARP Binding

Konfigurasi manual yang mengunci pasangan IP-MAC Address agar tidak bisa dipalsukan. Ini pencegahan serangan ARP spoofing.

D. Istilah Serangan (Attack)

Deauthentication Attack

Serangan yang memutuskan koneksi pengguna dari WiFi secara paksa. Pengguna tiba-tiba terputus tanpa alasan. Di jurnal ini, penyerang mengirim paket "deauth" palsu ke AP.

Rogue Access Point

Access Point palsu yang dipasang penyerang. Sepertinya WiFi resmi, tapi sebenarnya milik penyerang.

Evil Twin

Jenis serangan rogue access point yang membuat WiFi palsu dengan nama (SSID) sama atau mirip dengan WiFi asli. Pengguna dikira konek ke WiFi kantor, ternyata ke WiFi penyerang. Semua data (username, password) bisa dicuri.

ARP (Address Resolution Protocol)

Protokol yang menghubungkan IP Address dengan MAC Address di jaringan lokal.

ARP Spoofing / ARP Poisoning

Serangan memalsukan ARP sehingga penyerang bisa berada "di tengah" antara user dan jaringan. Akibatnya penyerang bisa: Membaca data user, Memblokir akses internet user, Memodifikasi data.
Ibaratnya: penyerang menyamar sebagai tukang pos, jadi semua surat (data) lewat tangannya dulu.

Aireplay-ng

Tool di Kali Linux untuk mengirim paket serangan ke jaringan WiFi, termasuk deauthentication.

Captive Portal

Halaman login yang muncul saat kamu konek WiFi (misal di hotel/kafe). Di serangan evil twin, penyerang membuat captive portal palsu untuk mencuri password kamu.

E. Istilah Tools

Kali Linux

Sistem operasi khusus untuk hacking/pentest. Banyak tool keamanan sudah terinstall di dalamnya.

Airgeddon

Tool di Kali Linux untuk audit WiFi. Bisa melakukan deauth, evil twin, dan mencuri password.

Evil Limiter

Tool untuk melakukan ARP spoofing, khususnya memblokir/membatasi akses internet user lain di jaringan yang sama.

Wireshark

Tool untuk melihat lalu lintas data di jaringan (sniffing). Di jurnal ini dipakai untuk membuktikan bahwa serangan deauth berhasil terdeteksi.

F. Istilah Keamanan WiFi

WPA2 (Wi-Fi Protected Access 2)

Standar enkripsi WiFi yang umum dipakai. Sudah ada celah keamanan.

WPA3

Standar enkripsi WiFi terbaru, lebih aman dari WPA2. Jurnal merekomendasikan upgrade ke WPA3.

Enkripsi

Proses mengacak data agar tidak bisa dibaca orang lain. Ibarat menulis surat pakai bahasa rahasia.

G. Istilah dari Hasil Penelitian

"AkuGanteng 2020"

Password WiFi asli PT PLN yang berhasil dicuri lewat serangan evil twin. Ini bukti bahwa serangan berhasil.
